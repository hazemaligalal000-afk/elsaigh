# Jawhara Jewellery Egypt - Local Homepage Archive

تم تحميل وتجهيز الصفحة الرئيسية لموقع **[Jawhara Egypt](https://jawharaegypt.com/)** بالكامل للعمل محلياً (Offline أو عبر خادم محلي) بكافة الملفات والصور والفيديوهات والخطوط والأكواد.

---

## 📁 هيكل المجلدات والملفات (Directory Structure)

```
mohamed alsaigh/
├── index.html                   # الصفحة الرئيسية الكاملة مع توجيه الروابط محلياً
├── assets/
│   ├── css/                     # ملفات التنسيق والـ Stylesheets (theme.css, styles.css, etc.)
│   ├── fonts/                   # خطوط الموقع الرسمية (GTStandard, Roboto بجميع أوزانها)
│   ├── images/                  # كافة الصور (الشعارات، البانرات، صور المجموعات والمنتجات)
│   ├── media/                   # فيديوهات الـ Hero الرئيسية عالية الجودة (MP4)
│   └── js/                      # ملفات الجافاسكريبت ومكونات العرض والتفاعلات
└── README.md                    # هذا الدليل التوضيحي
```

## 🚀 كيفية تشغيل الصفحة وعرضها (How to Run)

### 1. الفتح المباشر (Direct Double-Click):
يمكنك ببساطة النقر مرتين على ملف **`index.html`** لفتحه في أي متصفح (Chrome, Firefox, Edge, Safari). تعمل جميع الصور والخطوط والفيديوهات والتنسيقات مباشرة.

### 2. التشغيل عبر خادم محلي (Local Web Server):
إذا أردت تشغيلها عبر خادم ويب محلي:

**باستخدام Python:**
```bash
python3 -m http.server 8080
```
ثم فتح: [http://localhost:8080](http://localhost:8080) في المتصفح.

**أو باستخدام Node.js:**
```bash
npx serve .
```

## 💎 المحتويات المحملة (Downloaded Assets)
- **HTML كامل للمتجر:** تم تنقيحه وإعادة ربطه بمسارات الملفات المحلية بدون أي اعتماد على سيرفرات التحليلات الخارجية.
- **74 صورة وملف رسومي:** شملت شعارات Jawhara، البانرات العريضة، صور مجموعات المجوهرات، بطاقات المنتجات، وأيقونات الدفع.
- **فيديوهات الـ Hero الرئيسية (MP4):** تم تحميلها ودمجها للتشغيل التلقائي.
- **الخطوط الرسمية (WOFF/WOFF2):** جميع أوزان خط GTStandard وخط Roboto.
- **جميع التنسيقات (CSS):** أنماط الثيم والألوان والتنسيقات المتجاوبة مع الموبايل والكمبيوتر.
